## 怎么用这一段

**这个文件是给 README 准备的**：本仓目前是 **private**，而 npm 的包页面是从仓库取 README 里的
相对图片 —— 私有仓期间贴上去，npm 页面上会显示**裂图**。所以：

1. 等仓库转 public（或把图换成一个公开可访问的绝对地址）之后，
2. 把上面那张表格整段贴进 `README.md` 顶部（`## 安装` 之前），
3. 顺手把本文件的其余部分删掉，只留表格。

截图本身的生成方式见 `dsh-fly` 仓库的验收管线（真引擎 + Playwright）；本文件只负责存放与说明。
